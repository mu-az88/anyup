### `anyup/metrics.py` addition

```python
class TemporalCosineStream:
    """Chunk-by-chunk temporal_cosine: same per-pair math (float64, per pixel), peak memory ≈ 1 chunk + 1 frame."""
    def update(self, feats: Tensor, new_chunk: bool) -> None   # feats (t, C, H, W) of one chunk, in order;
                                                               # new_chunk=True → the pair (prev last, this first) is "cross"
    def result(self) -> Dict                                   # same keys as temporal_cosine: all, within, cross, per_pair, n_pairs, n_cross
```

- It keeps only the previous chunk's last frame (normalized, float64). Pairs within a chunk and the boundary pair use the same lines as `temporal_cosine`.

### Exp 2 (new protocol)

| Item | Value |
|---|---|
| Clips | 30 DAVIS-2017 val clips, all frames (T02) |
| Backbone | `videomae`, input 224, `guide_size=224` |
| Chunks | `CHUNK_SIZE=16` (fixed by VideoMAE), `OVERLAP=8` (backbone context only) |
| Conditions | `raw` (LR features 14², no upsampling), `bilinear`, `anyup2d`, `anyup3d` (`q_chunk_size=4096`) |
| Output size | guide size = 224² |
| Metric | `TemporalCosineStream`, `new_chunk = chunk_id > 0` → all / within / cross per clip |
| Rows | clip, condition, all, within, cross, n_pairs, n_cross, n_frames, n_tokens |
| Summary | mean ± std of `all` (and within / cross) per condition; `paired_stats(anyup3d, X)` on `all` for X in raw / bilinear / anyup2d |

- Per clip: the backbone chunks are computed **once** and kept on CPU (features (8, 768, 14, 14) + guide (8, 3, 224, 224) per chunk, ≈ 5 MB). Each condition then streams over them, so no full-clip upsampled tensor is ever stored.

### Exp 3 (new protocol)

| Item | Value |
|---|---|
| Clips | 30 val clips, all frames |
| Backbone | `swin_t`, `temporal_mode="per_frame"`, `norm="kinetics"`, input 224, `guide_size=PROP_SIZE` |
| Chunks | `CHUNK_SIZE=16`, `OVERLAP=0` |
| Conditions | `bilinear`, `anyup2d`, `anyup3d` (`q_chunk_size` = None at 56², as the old Exp 3; config knob) |
| Output size | `PROP_SIZE=56` |
| Propagation | `davis.propagate_labels(feats, ann0, TAU=0.07, TOP_K=7, N_LAST=6)` on GPU |
| Scoring | predictions resized to native (`resize_labels`, nearest) → `metrics.eval_clip_jf` (official, `1:-1`) → `summarize_jf` per condition |
| Saved | per-clip rows (J, F, J&F, n_objects, n_frames, n_scored) + `summarize_jf` (incl. per-object) in the summary JSON; palette PNGs via `save_mask_png` written locally to `/content/t05_exp3_masks/<run_name>/<condition>/<clip>/` (official layout), then zipped to `OUTPUT_DIR/<run_name>/masks.zip` |
| Stats | `paired_stats(anyup3d, X)` on per-clip J&F for X in bilinear / anyup2d |

- Per clip, the upsampled features (T, 768, 56, 56) are concatenated: ≤ 104 × 768 × 56² × 4 B ≈ 1 GB. The affinity per frame is 3136 × 21952 floats ≈ 275 MB (T04).

### Compute-cost lines (commented in the config cell with their dependents)

- `CHUNK_SIZE` (Exp 2: 16, fixed by VideoMAE; Exp 3: 16): frames per backbone/AnyUp3D call → peak memory. Dependent: `Q_CHUNK`, `OUTPUT_SIZE`/`PROP_SIZE`, `OVERLAP` (< `CHUNK_SIZE`).
- `OVERLAP` (8 / 0): extra backbone frames per chunk → cost × 16/(16−overlap). Dependent: `CHUNK_SIZE`; a multiple of the backbone `temporal_stride` (VideoMAE 2).
- `GUIDE_SIZE`/output 224 (Exp 2), `PROP_SIZE` 56 (Exp 3): output resolution → memory/time of every upsampler; Exp 3 also the affinity size. Dependent: `Q_CHUNK`, `N_LAST`.
- `Q_CHUNK` (4096 / None): AnyUp3D query chunk → peak memory. Dependent: `CHUNK_SIZE`, output size.
- `N_LAST=6`: propagation context → affinity memory. Dependent: `PROP_SIZE`.

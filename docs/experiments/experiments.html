AnyUp3D experiments

Documentation of the four evaluation notebooks (Exp 0–3): what each measures, how it runs, and the shared code it calls.

Documented commit 13fce8c on experiments-task02

All experiments share one pipeline: a frozen backbone produces low-resolution features and an ImageNet-normalized guide image (anyup.backbones); an upsampler maps the features to the guide resolution (anyup.upsamplers); a metric scores the result (anyup.metrics). Every comparison uses the same backbone output for all upsamplers, so the upsampler is the only variable.

Three upsamplers are compared throughout: bilinear interpolation, the published AnyUp (2D), applied frame by frame, and AnyUp3D, applied to a chunk of frames in one call. AnyUp3D was trained on VideoMAE features only; results on DINOv2 (Exp 1) and Video Swin-T (Exp 3) are therefore zero-shot.

Reproducibility

Each notebook clones the repository at a fixed branch on Colab (Cell 1), sets CUBLAS_WORKSPACE_CONFIG before CUDA starts, and seeds Python, NumPy and PyTorch with deterministic kernels (set_seed). Exp 0 also measures a non-deterministic fast mode.

Results are written by save_results: a per-item CSV (clip, image or measurement) and a summary JSON holding the summary, the full config and the environment (git commit and dirty flag, GPU, CUDA, package versions, checkpoint SHA-256).

Exp 0 · Efficiency

experiments/exp0_efficiency.ipynb · T08 (renamed from Exp 4)

Exp 0 measures the inference cost of each upsampler: parameter count, weight size, run time and peak GPU memory of one forward pass under no_grad. The cost does not depend on image content, so the inputs are synthetic tensors of the shapes used in Exp 2, and no dataset or backbone is loaded.

The main row is the Exp 2 setting (224² output, 8 feature frames, AnyUp3D query chunk 4096), measured once with non-deterministic kernels (fast) and once with the deterministic seeding of Exp 1–3. A sweep over output size, frames and query chunk shows how the cost scales; rows that run out of memory are recorded as OOM.

Data flow

  1. synthetic features(T, 768, 14, 14)
  2. synthetic guide(T, 3, S, S)
  3. upsamplerone call per chunk
  4. output(T, 768, S, S)
  5. CUDA events + peak memorymedian, IQR, MiB

Main row: T = 8, S = 224, q = 4096. Sweep: S ∈ {56, 112, 224}, T ∈ {4, 8, 16}, AnyUp3D q ∈ {None, 1024, 4096}.

4Measurement

Builds synthetic inputs from a fixed seed and times one call: warm-up calls, then repeated calls timed with CUDA events. Peak memory is read after resetting the peak counter; the extra peak is the peak minus the memory in use before the calls. An out-of-memory error is recorded as OOM.

# ── Cell 4 · Measurement ───────────────────────────────────────────────────
def make_inputs(frames, out_size):
    g = torch.Generator(device="cpu").manual_seed(SEED)
    feats = torch.randn(frames, FEAT_DIM, FEAT_GRID, FEAT_GRID, generator=g)   # (T, 768, 14, 14) raw features
    guide = torch.randn(frames, 3, out_size, out_size, generator=g)            # (T, 3, S, S) "normalized" guide
    return BackboneOutput(features=feats.to(DEVICE), guide=guide.to(DEVICE), meta={})

def measure(fn, warmup, repeats):
    # → per-call times (ms), memory in use before the timed calls, peak during them, output shape
    for _ in range(warmup):
        out = fn(); del out
    torch.cuda.synchronize()
    torch.cuda.reset_peak_memory_stats()
    base = torch.cuda.memory_allocated()                   # inputs + weights (+ allocator state)
    times, shape = [], None
    for _ in range(repeats):
        start, end = torch.cuda.Event(enable_timing=True), torch.cuda.Event(enable_timing=True)
        start.record()
        out = fn()
        end.record()
        torch.cuda.synchronize()
        times.append(start.elapsed_time(end))
        shape = tuple(out.shape)
        del out
    return times, base, torch.cuda.max_memory_allocated(), shape

def run_row(part, mode, name, out_size, frames, q_chunk):
    row = dict(part=part, mode=mode, upsampler=name, out_size=out_size, frames=frames,
               q_chunk=q_chunk if name == "anyup3d" else None, repeats=REPEATS)
    up = UPS[name]
    if name == "anyup3d":
        up.q_chunk_size = q_chunk                          # ↓ AnyUp3D query chunk for this row
    chunk = make_inputs(frames, out_size)
    try:
        times, base, peak, shape = measure(lambda: up(chunk, output_size=out_size).features, WARMUP, REPEATS)
        q1, med, q3 = np.percentile(times, [25, 50, 75])
        row.update(status="ok", median_ms=float(med), iqr_ms=float(q3 - q1), per_frame_ms=float(med / frames),
                   peak_total_mib=peak / 2**20, peak_extra_mib=(peak - base) / 2**20, out_shape=list(shape))
    except torch.cuda.OutOfMemoryError:
        row.update(status="OOM")
    finally:
        del chunk
        gc.collect()
        torch.cuda.empty_cache()
    if row["status"] == "ok":
        print(f"{part:<5} {mode:<13} {name:<9} S={out_size:<3} T={frames:<2} q={str(row['q_chunk']):<5} "
              f"{row['median_ms']:9.2f} ms (IQR {row['iqr_ms']:.2f})  {row['per_frame_ms']:8.2f} ms/frame  "
              f"peak {row['peak_total_mib']:8.1f} MiB  extra {row['peak_extra_mib']:8.1f} MiB")
    else:
        print(f"{part:<5} {mode:<13} {name:<9} S={out_size:<3} T={frames:<2} q={str(row['q_chunk']):<5} OOM")
    return row

Exp 1 · ADE20K linear probe

experiments/exp1_ade20k_probe.ipynb · T06 refactor, T07 clean-up

Exp 1 checks that AnyUp3D does not lose spatial quality on single images. DINOv2-base features of ADE20K images (T = 1) are upsampled to 224², and a linear 1×1 convolution is trained on them for each upsampler; the metric is mIoU over the 150 classes at 224².

The probe is deliberately weak, so differences in mIoU reflect the upsampled features rather than the head. Each seed gives every upsampler the same head initialization and the same data order. AnyUp3D never saw DINOv2 features or still images in training, so this test is zero-shot.

Data flow

  1. imageresized to 224² (squashed)
  2. DINOv2-base(B, 768, 16, 16), fp16 cache
  3. upsampler.forward_images(B, 768, 224, 224)
  4. 1×1 conv head(B, 150, 224, 224)
  5. mIoUlabel 0 ignored

Masks are resized with nearest neighbour to 224². forward_images treats the batch as unrelated images (each a one-frame clip), never as consecutive frames.

# ── Cell 4 · Head, train, evaluate, checkpoints ────────────────────────────
def make_head():
    return nn.Conv2d(FEAT_DIM, NUM_CLASSES, kernel_size=1).to(DEVICE)

def upsample(condition, guide, feats):
    # guide (B, 3, S, S), feats (B, C, h, w) on DEVICE → (B, C, S, S). forward_images: B unrelated images
    chunk = BackboneOutput(features=feats, guide=guide, meta={})
    return UPS[condition].forward_images(chunk, output_size=IMG_SIZE).features

def train_one_epoch(head, optimizer, condition, loader):
    head.train()
    losses = []
    for guide, feats, masks in loader:
        guide, feats = guide.to(DEVICE), feats.to(DEVICE)
        masks = masks.to(DEVICE) - 1                       # shift: 1–150 → 0–149; 0 → -1 (ignore)
        logits = head(upsample(condition, guide, feats))   # (B, 150, S, S)
        loss = F.cross_entropy(logits, masks, ignore_index=-1)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        losses.append(loss.item())
    return losses

@torch.no_grad()
def evaluate(head, condition, loader, per_image):
    head.eval()
    conf_mat = torch.zeros(NUM_CLASSES, NUM_CLASSES, dtype=torch.long)
    scores = []
    for guide, feats, masks in loader:
        guide, feats, masks = guide.to(DEVICE), feats.to(DEVICE), masks.to(DEVICE)
        logits = head(upsample(condition, guide, feats))
        metrics.update_conf_mat(conf_mat, logits, masks, NUM_CLASSES, IGNORE_INDEX)
        if per_image:
            scores.extend(metrics.image_miou(logits, masks, NUM_CLASSES, IGNORE_INDEX))
    return metrics.compute_miou(conf_mat), conf_mat, scores

def head_path(condition, seed):
    return HEAD_DIR / f"{condition}_seed{seed}.pt"

def save_head(condition, seed, state):
    HEAD_DIR.mkdir(parents=True, exist_ok=True)
    path = head_path(condition, seed)
    tmp = path.with_suffix(".part")
    torch.save(state, tmp)
    os.replace(tmp, path)        # a disconnect during the save leaves the previous checkpoint intact

def run_seed(seed, condition):
    set_seed(seed)                                         # same seed → same head init for every condition
    head = make_head()
    optimizer = torch.optim.AdamW(head.parameters(), lr=LR, weight_decay=WEIGHT_DECAY)
    scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=LR_DECAY_STEP, gamma=LR_DECAY_GAMMA)
    g = torch.Generator().manual_seed(seed)                # same seed → same data order for every condition
    history, start_epoch, scores = [], 0, None

    path = head_path(condition, seed)
    if path.exists():
        ckpt = torch.load(path, map_location=DEVICE, weights_only=True)
        head.load_state_dict(ckpt["head"])
        optimizer.load_state_dict(ckpt["optimizer"])
        scheduler.load_state_dict(ckpt["scheduler"])
        g.set_state(ckpt["gen_state"].cpu())
        history, start_epoch, scores = ckpt["history"], ckpt["epoch"], ckpt["per_image"]
        print(f"    resumed after epoch {start_epoch}: mIoU {ckpt['miou']:.2f}")
        if start_epoch >= NUM_EPOCHS:
            return ckpt["miou"], history, scores

    train_loader = DataLoader(train_ds, batch_size=BATCH_SIZE,       # A100: 16, T4: 4. Dependent: Q_CHUNK, IMG_SIZE
                              shuffle=True, generator=g,
                              num_workers=NUM_WORKERS,               # A100: 4, T4: 2
                              pin_memory=True)
    val_loader   = DataLoader(val_ds, batch_size=BATCH_SIZE,         # A100: 16, T4: 4. Dependent: Q_CHUNK, IMG_SIZE
                              shuffle=False,
                              num_workers=NUM_WORKERS,               # A100: 4, T4: 2
                              pin_memory=True)

    for epoch in range(start_epoch + 1, NUM_EPOCHS + 1):             # A100: 3 epochs, T4: 1
        t0 = time.time()
        losses = train_one_epoch(head, optimizer, condition, train_loader)
        scheduler.step()
        t1 = time.time()
        last = epoch == NUM_EPOCHS
        miou, conf_mat, epoch_scores = evaluate(head, condition, val_loader, per_image=last)
        loss = float(np.mean(losses))
        history.append(dict(epoch=epoch, loss=loss, miou=miou, train_s=t1 - t0, val_s=time.time() - t1))
        print(f"    epoch {epoch:02d}/{NUM_EPOCHS}  loss={loss:.4f}  mIoU={miou:.2f}  "
              f"train {t1 - t0:.0f} s  val {time.time() - t1:.0f} s  "
              f"peak {torch.cuda.max_memory_allocated() / 2**30:.1f} GiB")
        scores = epoch_scores if last else None
        save_head(condition, seed, dict(head=head.state_dict(), optimizer=optimizer.state_dict(),
                                        scheduler=scheduler.state_dict(), gen_state=g.get_state(),
                                        epoch=epoch, miou=miou, history=history, per_image=scores))
    return miou, history, scores

Exp 2 · Temporal consistency

experiments/exp2_temporal_consistency.ipynb · T05 refactor, T07 clean-up

Exp 2 measures temporal consistency: for each pair of adjacent feature frames, the cosine similarity between the two feature vectors at each pixel, averaged over pixels and then over the pairs of a clip. A temporally stable upsampler should not add flicker to the features it upsamples. The raw low-resolution VideoMAE features are reported as a reference.

VideoMAE accepts exactly 16 frames, so long clips are processed in chunks. Pairs that cross a chunk boundary are reported separately (cross) from pairs inside a chunk (within), since AnyUp3D sees each chunk independently.

Data flow

  1. clip, all N frames(N, 3, 480, W)
  2. chunks of 16, overlap 8backbone context only
  3. VideoMAE-base(t, 768, 14, 14) + guide (t, 3, 224, 224)
  4. upsampler(t, 768, 224, 224)
  5. TemporalCosineStreamfloat64, per pixel
  6. per clipall / within / cross

t ≤ 8 feature frames per chunk (VideoMAE tubelet 2). Overlapping outputs are kept from the earlier chunk, so a clip of N frames gives ⌈N/2⌉ feature frames, frames 0, 2, 4, … (checked per clip).

    n_frames = len(src)
    # backbone ONCE per clip; chunks stay on the GPU (≈ 10 MB each at 224²)
    chunks = list(iter_backbone_chunks(bb, src, chunk_size=CHUNK_SIZE, overlap=OVERLAP))

Exp 3 tests whether more consistent features help a downstream video task without any training. In semi-supervised video object segmentation by non-parametric label propagation (Jabri et al. 2020; DINO protocol), the ground-truth mask of frame 0 is carried to every later frame through feature affinities with frame 0 and the six preceding frames. The predictions are scored with the official DAVIS-2017 J&F (region similarity J and boundary accuracy F).

Video Swin-T, run frame by frame, was never seen in AnyUp3D training, and the propagation has no learned component. The absolute J&F is therefore a lower bound; the comparison between upsamplers on identical backbone features is the result.

  1. clip, all T frames(T, 3, 480, W)
  2. Swin-T per frame, 224(t, 768, 7, 7) + guide (t, 3, 56, 56)
  3. upsampler(t, 768, 56, 56)
  4. concatenate chunks(T, 768, 56, 56)
  5. propagate_labelsτ 0.07, top-k 7, frame 0 + last 6
  6. PNG at native size(T, 480, W)
  7. eval_clip_jf → summarize_jfJ, F, J&F

Chunks of 16 frames without overlap: Swin-T runs per frame (each frame duplicated into a two-frame clip), so overlap would not change any feature. The first and last frames are not scored (official protocol).

Protocol vs thesis

  • All frames of each clip are used; the thesis used every 12th frame.
  • AnyUp3D receives the ImageNet-normalized guide it was trained with; the thesis passed raw [0, 1] frames.
  • Swin-T inputs use the Kinetics statistics of its weights; the thesis used ImageNet statistics.
  • Scoring follows the official DAVIS toolkit: first and last frame not scored, per-object aggregation, toolkit boundaries. On the same masks the thesis metric gave about +0.02 J&F more.
  • Propagation runs on float32 features; the thesis propagated float16-cached features.
  • On the old protocol, the refactored code reproduced the old Exp 3 upsampled features and masks exactly (T05 regression check).

Known issues

  • Phase BOn drift-straight, propagation with AnyUp3D features collapses (J&F 0.033 vs 0.297 for bilinear in the T05 run); the masks are kept for inspection.

Paired comparison of per-item scores (clips, objects or seeds), higher = better.

Sign test: exact binomial on non-tied pairs (ties dropped), p=0.5.
Wilcoxon signed-rank: scipy default (zero differences dropped).

A test that can't be computed (e.g. all pairs tied, n < 2) gives None.
